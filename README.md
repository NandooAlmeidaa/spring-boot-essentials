# 🚀 Spring Boot Essentials

> Projeto desenvolvido para consolidar conhecimentos em **Java** e **Spring Boot**, aplicando boas práticas de desenvolvimento backend, arquitetura em camadas e construção de APIs REST.

## 📖 Sobre o Projeto

Este repositório reúne exemplos práticos e implementações utilizando o ecossistema Spring Boot, com o objetivo de aprofundar conhecimentos em desenvolvimento backend moderno.

Durante o desenvolvimento foram aplicados conceitos de:

* Arquitetura em camadas (Controller, Service e Repository)
* Construção de APIs REST
* Persistência de dados com Spring Data JPA
* Validação de dados
* Tratamento global de exceções
* Boas práticas de organização de código
* Versionamento utilizando Git e GitHub

## ⚙️ Como Executar

### Pré-requisitos

* Java 21+
* Maven 3.9+
* IDE (IntelliJ IDEA ou VS Code)

### Clone o repositório

```bash
git clone https://github.com/NandooAlmeidaa/spring-boot-essentials.git
```

Entre na pasta

```bash
cd spring-boot-essentials
```

Execute a aplicação

```bash
./mvnw spring-boot:run
```

Ou

```bash
mvn spring-boot:run
```

A aplicação estará disponível em:

```text
http://localhost:8080
```
